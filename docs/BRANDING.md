# SetupScope Brand Assets

SetupScope — Windows Desktop Development Toolkit.

The Precision S mark uses a segmented scope ring. The banner uses layered application windows. Black, white and red are the brand colors. The W, D, D and T tagline initials match the red in Scope.

Use `assets/setupscope-logo.png`, `assets/setupscope-banner.png` and `assets/setupscope.ico`. The SVG files are self-contained wrappers around the selected artwork. Windows icon sizes are mechanical conversions.
