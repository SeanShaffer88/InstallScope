# SetupScope branding

SetupScope — Windows Desktop Development Toolkit.

The selected Precision S symbol uses a segmented scope ring. The banner uses layered application windows. Black, white and red are the brand colors; the W, D, D and T tagline initials match the red in Scope.

Assets: `assets/setupscope-logo.png`, `assets/setupscope-banner.png`, and `assets/setupscope.ico`. The PNG files are the original selected AI-generated artwork; size variants and the Windows icon are mechanical conversions. Self-contained SVG entry points embed the raster artwork as PNG data and are not independent vector masters.

Historical screenshots and published binaries retain their original appearance. Compatibility data paths, transfer extensions, shell verb identifiers and singleton locks may retain the former SetupSweep name intentionally. No existing data is renamed or deleted.

Brand verification (2026-10-22): checked README image targets, Cargo package/library/binary names, Windows version resources/manifest, installer and CI paths, and repository metadata. Matched selected PNG artwork and generated ICO/size variants between publication and focused local checkouts by SHA-256. Opened the focused local board and all five tool windows and captured their SetupScope titles and scoped S icons. Fresh README captures replace older featured images; archived captures/releases retain provenance. Legacy storage/transfer/shell/task identifiers remain deliberate compatibility exceptions.
